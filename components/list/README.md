# List

Duas listas sem marcador nativo: ponto de acento (`.blist`) e seta (`.arrlist`).

## Arquivos

- [`list.css`](list.css) — estilos do componente.
- [`list.html`](list.html) — preview isolado (abra no navegador).

## Classes

- `.blist`
- `.arrlist`
- `.dot`
- `.arr`

## Variações

- Marcador (ponto)
- Seta

## Tokens-chave

`--accent-text`, `--r-pill`

## Uso

```html
<ul class="blist"><li><span class="dot"></span>Item</li></ul>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
