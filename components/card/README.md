# Card

Bloco de conteúdo sobre superfície de vidro. Variações de destaque, sucesso e alerta usam acento contido.

## Arquivos

- [`card.css`](card.css) — estilos do componente.
- [`card.html`](card.html) — preview isolado (abra no navegador).

## Classes

- `.bcard`
- `.cards-3` (grade de 3)
- `.bcard.surf`

## Variações

- Padrão
- `featured` (azul)
- `success` (verde)
- `warning` (amarelo)
- `surf` (vidro)

## Tokens-chave

`--surface-2`, `--border`, `--glow`, `--azul`, `--verde`, `--warning`, `--r-lg / --r-xl`

## Uso

```html
<div class="bcard"><h4>Título</h4><p>Descrição.</p></div>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
