# Badge

Selo de texto com contorno, pensado para fundo claro. Use para rótulos de verificação ou certificação.

## Arquivos

- [`badge.css`](badge.css) — estilos do componente.
- [`badge.html`](badge.html) — preview isolado (abra no navegador).

## Classes

- `.badge`

## Variações

- Padrão
- Hover

## Tokens-chave

`--cinza`, `--cinza-claro`, `--preto`, `--r-md`

## Uso

```html
<span class="badge">Empresa verificada</span>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
