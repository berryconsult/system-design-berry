# Button

Ação primária. Azul sólido para a ação principal, verde para a alternativa, fantasma para a secundária.

## Arquivos

- [`button.css`](button.css) — estilos do componente.
- [`button.html`](button.html) — preview isolado (abra no navegador).

## Classes

- `.btn`
- `.btn-primary`
- `.btn-green`
- `.btn-ghost`

## Variações

- Primário (azul)
- Verde
- Fantasma
- Desabilitado (`disabled`)

## Tokens-chave

`--azul`, `--verde`, `--border-strong`, `--r-sm`, `--duration-normal`, `--easing-smooth`

## Uso

```html
<button class="btn btn-primary">Falar com a Berry</button>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
