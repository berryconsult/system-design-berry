# Pill

Cápsula neutra para listar princípios, valores ou atributos. Sem cor de marca.

## Arquivos

- [`pill.css`](pill.css) — estilos do componente.
- [`pill.html`](pill.html) — preview isolado (abra no navegador).

## Classes

- `.pill`
- `.pillrow` (agrupador)

## Variações

- Padrão

## Tokens-chave

`--surface-3`, `--border`, `--r-pill`

## Uso

```html
<div class="pillrow"><span class="pill">Coragem</span><span class="pill">Honra</span></div>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
