# Divider

Divisor com barra de acento vertical e linha. A barra cresce no hover.

## Arquivos

- [`divider.css`](divider.css) — estilos do componente.
- [`divider.html`](divider.html) — preview isolado (abra no navegador).

## Classes

- `.divider-accent`
- `.vbar`
- `.line`

## Variações

- Padrão
- Hover

## Tokens-chave

`--azul`, `--border`, `--r-pill`, `--duration-normal`

## Uso

```html
<div class="divider-accent"><span class="vbar"></span><span class="line"></span></div>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
