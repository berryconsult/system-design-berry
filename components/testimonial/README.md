# Testimonial

Depoimento de cliente. Sempre sobre superfície clara, com avatar, nome e avaliação.

## Arquivos

- [`testimonial.css`](testimonial.css) — estilos do componente.
- [`testimonial.html`](testimonial.html) — preview isolado (abra no navegador).

## Classes

- `.testi`
- `.top`
- `.av`
- `.who`

## Variações

- Padrão (fundo claro)

## Tokens-chave

`--cinza-claro`, `--cinza`, `--preto`, `--r-lg`

## Uso

```html
<div class="testi"><div class="top">...</div><h5>Título</h5><p>Texto.</p></div>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
