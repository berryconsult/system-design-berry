# Tag

Marcador compacto para categorias. Verde por padrão, azul na variação `.b`.

## Arquivos

- [`tag.css`](tag.css) — estilos do componente.
- [`tag.html`](tag.html) — preview isolado (abra no navegador).

## Classes

- `.tag`
- `.tag.b`

## Variações

- Verde (padrão)
- Azul (`.b`)

## Tokens-chave

`--verde`, `--cinza-claro`, `--r-sm`, `--duration-normal`

## Uso

```html
<span class="tag">RevOps</span> <span class="tag b">B2B</span>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
