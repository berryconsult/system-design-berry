# Stat

Bloco de prova social: número grande com rótulo. O prefixo usa o tom fantasma.

## Arquivos

- [`stat.css`](stat.css) — estilos do componente.
- [`stat.html`](stat.html) — preview isolado (abra no navegador).

## Classes

- `.stat`
- `.stats-grid`
- `.n`
- `.l`
- `.ghost`

## Variações

- Padrão

## Tokens-chave

`--surface-2`, `--fs-display-lg`, `--font-display`

## Uso

```html
<div class="stat"><div class="n"><span class="ghost">+</span>5mil</div><div class="l">Clientes</div></div>
```

> Depende de [`tokens/tokens.css`](../../tokens/tokens.css). Estilos de elemento (foco, reset) vêm de [`styles/`](../../styles/).
