# Berry Design System

Sistema de design oficial da **Berry Consultoria**. O arquivo [`index.html`](index.html) é autocontido: abre direto no navegador, sem build nem dependências. Todos os tokens, logotipos e ícones estão embutidos no próprio HTML.

## Como visualizar

Abra `index.html` em qualquer navegador. Se o GitHub Pages estiver ativo neste repositório, a página é servida na raiz automaticamente.

## O que contém

- **Fundamentos de marca** e guia de tom de voz.
- **Paleta fechada de cinco cores** (Preto, Cinza, Cinza Claro, Azul, Verde), com tokens em CSS custom properties.
- **Modo escuro e modo claro**, alternáveis na própria página.
- **Logotipos adaptativos** em SVG inline: símbolo, horizontal, horizontal com sufixo "Consultoria" e vertical. O logotipo herda a cor do contexto; os anéis preservam azul e verde.
- **Iconografia** em selos com gradiente de cinza.
- **Cores funcionais do sistema**, tipografia, componentes e selos de confiança.

## Origem

Esta página espelha o projeto de design system mantido no Claude Design. O HTML é a representação portátil e navegável do sistema; alterações de marca devem ser refletidas nas duas superfícies.
