# Assets · Ícones

Os 15 glifos oficiais, geometria na referência Lucide, viewBox `0 0 150 150`. Exportados como SVG de traço (`fill="none"`, `stroke="currentColor"`, `stroke-width="6"`), prontos para herdar a cor do contexto.

metas · relacionamento · produtividade · valor · financeiro · estrategia · seguranca · protecao · crescimento · ideias · presenca · pessoas · qualidade · conexao · resultados

## Uso

Como traço simples, herdando a cor:

```html
<img src="assets/icons/estrategia.svg" width="24" alt="Estratégia">
```

O tratamento oficial em badge (tile escuro, borda em gradiente, relevo branco-cinza) é o componente [`icon-badge`](../../components/icon-badge). Veja as diretrizes em [`foundations/iconography`](../../foundations/iconography).
