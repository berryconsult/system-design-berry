# Assets · Logotipo

Vetores oficiais da marca, extraídos com fidelidade de caminho do arquivo-fonte. O logotipo herda `currentColor`; os anéis preservam azul (`#0D30A4`) e verde (`#5EC072`).

| Arquivo | Assinatura | viewBox |
|---------|------------|---------|
| `berry-symbol.svg` | Símbolo (3 anéis, 2 azuis + 1 verde) | 0 0 1080 1080 |
| `berry-symbol-mono.svg` | Símbolo monocromático (`currentColor`) | 0 0 1080 1080 |
| `berry-horizontal.svg` | Símbolo + "berry" | 0 0 1920 1080 |
| `berry-horizontal-suffix.svg` | Horizontal + descritor "Consultoria" | 0 0 1349.94 268.23 |
| `berry-vertical.svg` | Símbolo sobre "berry" | 0 0 1080 1080 |
| `berry-vertical-suffix.svg` | Vertical + sufixo | 0 0 1080 1080 |

Diretrizes completas de uso, área de proteção, tamanho mínimo e proibições em [`foundations/logo`](../../foundations/logo).

> Como SVG embutido (`<svg><use>`), o logotipo herda a cor do contexto. Como `<img>`, o `currentColor` resolve para preto; nesse caso prefira fundo claro ou use a versão monocromática adequada.
