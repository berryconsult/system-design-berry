# Logotipo

O logotipo é o desenho oficial da palavra "berry" ao lado do símbolo: um cacho de três anéis, dois azuis (`#0D30A4`) e um verde (`#5EC072`). A palavra "berry" tem desenho próprio e nunca é digitada em fonte.

## Assinaturas

Os vetores oficiais estão em [`assets/logo/`](../../assets/logo). O logotipo herda `currentColor`; os anéis preservam azul e verde.

| Arquivo | Assinatura |
|---------|------------|
| `berry-symbol.svg` | Apenas o símbolo (3 anéis). |
| `berry-symbol-mono.svg` | Símbolo monocromático (`currentColor`). |
| `berry-horizontal.svg` | Símbolo + "berry" na horizontal. |
| `berry-horizontal-suffix.svg` | Assinatura horizontal com o descritor "Consultoria", para a primeira aparição institucional. |
| `berry-vertical.svg` | Símbolo sobre "berry". |
| `berry-vertical-suffix.svg` | Vertical com o sufixo. |

## Versões de cor

A versão padrão (azul + verde) pede fundo de bom contraste: preto, cinza claro ou branco. Sobre cor cheia, imagem ou baixo contraste, use a versão monocromática que preservar a legibilidade.

## Área de proteção

Reserve ao redor do logo um espaço livre de no mínimo a altura de um anel do símbolo. Nenhum texto, imagem ou borda invade essa margem.

## Tamanho mínimo

Símbolo a partir de 20px; horizontal a partir de 24px. O lockup com sufixo exige mais altura para manter o descritor legível.

## Não faça

Não recolora, gire, distorça, estique nem aplique sombra ou contorno. Não altere a relação dos anéis (dois azuis e um verde) nem a posição do sufixo. Não recrie o logotipo com fontes do sistema. Não aplique a versão colorida sobre fundo de baixo contraste.
